# Notification sounds

Original synthesized tones generated by `scripts/generate-notification-sounds.py`.
No operating system sound files are copied or required. Each file is mono,
44.1 kHz, 16-bit PCM WAV and lasts less than one second.

| File | Notification |
| --- | --- |
| approval.wav | A question or approval needs attention |
| completion.wav | A conversation has completed |
| reminder.wav | A to-do reminder is due |
| scheduled.wav | A scheduled to-do execution has completed |
| attention.wav | A scheduled execution was missed or needs review |
| error.wav | A scheduled execution did not complete |

Both desktop package configurations copy this directory to
`resources/notification-sounds`, outside `app.asar`, for native audio playback.
Development builds read the assets from this directory.
