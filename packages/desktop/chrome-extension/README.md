# AI Hub 网页账号连接（0.2.0）

扩展将你主动选择的 ChatGPT、Gemini、Grok 网页对话连接到本机 AI Hub。账号与登录会话保存在日常 Chrome。AI Hub 显示文字消息、代码块和回复状态，无需截图，也不改变 Chrome 网页尺寸。

1. 启动 AgentRoam，进入 AI Hub，点击「连接 Chrome」。
2. Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」，加载本文件所在的 `chrome-extension` 文件夹。
3. 已安装旧版：在扩展卡片上点击刷新，确认版本为 **0.2.0**。只刷新 AI 网站或重启 AI Hub 不会更新扩展。
4. 首次连接：在 AI Hub 复制连接码，到扩展弹窗粘贴并点击「连接本机 AI Hub」。已有配对码会保留。
5. 在日常 Chrome 正常登录。登录完成后，在每个 AI 网站打开扩展，点击「连接当前 AI 标签页」。
6. 回到 AI Hub，在下方输入框选择站点并发送。各栏会同步当前网页对话的文字变化；也可在 Chrome 继续聊天。

消息提交后会检查网页是否出现新的用户消息。网页已有其他草稿、尚在生成、发送按钮不可用或未确认收到消息时，会返回具体原因；不会自动重复提交。遇到「未确认」时，先检查原网页。

模型选择、历史会话、特殊附件和网站特有功能在 Chrome 原网页中操作。图片发送依赖网站现有上传入口，上传限制仍由网站决定。回复读取依赖各网站 DOM，站点改版可能需要更新扩展。当前同步最近 100 条、单条最多 50,000 字符，纯文本与代码可在桌面复制；图片回复用占位文字提示，原图在 Chrome 查看。

Chrome 的调试提示来自扩展用于定位输入框和发送浏览器输入事件的权限。扩展不读取 Cookie、不控制认证页面；进入登录页会断开，登录后需重新接入。关闭标签页、断开扩展或退出桌面端会释放控制。配对码仅用于本机连接，不要公开分享。
