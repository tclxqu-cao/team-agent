- 领域层以 `entities.ts` 定义核心类型与接口边界：`ProjectFile`、`AssembledContext`、`IContextLoader`、`IContextAssembler`、`AssembleInput`，并通过 `index.ts` 统一对外导出。
- `ContextLoader` 实现 `IContextLoader`，基于 `node:fs/promises` 与 `node:path` 扫描根目录及子目录，优先加载已知项目文件（如 `CLAUDE.md`、`README.md`），并递归查找额外 `CLAUDE.md`，同时跳过 `node_modules`、`.git`、`dist`。
- `ContextAssembler` 实现 `IContextAssembler`，依赖注入 `IContextLoader`；按“基础系统提示 → 环境信息 → 项目上下文 → 技能 → 工具 → 记忆”的顺序拼接 `systemPrompt`，使用字符/4估算令牌并在超预算时按段落截断，最终返回包含历史消息与令牌统计的 `AssembledContext`。
- 测试位于 `__tests__/ContextAssembler.test.ts`，通过真实 `ContextLoader` 与 `ContextAssembler` 组合验证默认提示、可选片段注入、自定义系统提示与预算截断行为，形成模块内闭环验证。
