# AgentRoam macOS arm64 Preview Release Implementation Plan

> **For the main agent:** Implement this plan directly in the current session. Do not dispatch implementation or code-review subagents. After all development tasks are complete, run the affected unit tests and fix any failures before reporting completion. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the existing CLI as `agentroam@0.2.0-preview.1` for macOS arm64 under the npm `preview` dist-tag.

**Architecture:** Keep the current single-package standalone runtime, but describe its actual native compatibility in npm metadata with `os: ["darwin"]` and `cpu: ["arm64"]`. Rename the public package, executable, generated tarball, audit expectations, and release commands together so install and verification paths remain consistent.

**Tech Stack:** Node.js 22, npm 11, TypeScript, Vitest, Next.js standalone runtime, native `better-sqlite3` and `node-pty` modules.

## Global Constraints

- Public package name: `agentroam`.
- Public CLI command: `agentroam`.
- Preview version: `0.2.0-preview.1`.
- Supported platform for this preview: macOS arm64 only.
- npm dist-tag: `preview`; do not update `latest`.
- Publish explicitly to `https://registry.npmjs.org`.
- Keep `publishConfig.provenance=true` for the future CI release; override provenance only on this local preview publish.
- Do not include `.env.local`, session data, desktop sources, SDK sources, or repository-only files in the tarball.
