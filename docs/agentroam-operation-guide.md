# AgentRoam 操作指南：安装、多设备配对与远程授权

适用于需要用手机、平板或另一台电脑访问自己电脑的用户。下面以 CLI 后台服务 + 浏览器为主线，手机无需安装桌面 App。

> 安装命令不包含固定 AgentRoam 版本号，默认获取 npm 的 `preview` 通道版本。功能说明按当前项目实现核对；安装后是否具备这些入口，取决于对应功能是否已发布到该通道。

## 1. 在被访问的电脑上安装

被访问的电脑需要保持开机、联网，并运行 AgentRoam。macOS 安装脚本支持 Apple Silicon（M 系列），Windows 安装脚本支持 x64。远程桌面画面和鼠标键盘控制当前支持 macOS 14 及以上的 Apple Silicon 电脑；Windows 可使用终端和文件功能。

### macOS

1. 按 `Command + 空格`，搜索“终端”，按回车打开。
2. 先进入希望通过 AgentRoam 访问的文件夹。例如要访问 Documents，执行：

   ```bash
   cd "$HOME/Documents"
   ```

3. 复制下面这一整行到终端，按回车：

   ```bash
   curl -fsSL https://gitee.com/caoqu/team-agent/raw/master/packages/cli/install/install-agentroam.sh | sh
   ```

4. 等待安装和后台服务启动完成。安装器会自动检查或准备 Node 环境。
5. 如果询问是否下载桌面 App：只用浏览器时按回车跳过；需要桌面 App 时输入 `y`，下载后打开安装文件完成安装。
6. 如果提示找不到 `agentroam`，在当前终端执行下面这行再继续；长期使用可按安装器提示配置 PATH：

   ```bash
   export PATH="$HOME/.local/bin:$PATH"
   ```

### Windows

1. 打开开始菜单，搜索“PowerShell”，打开普通 PowerShell 窗口，无需管理员权限。
2. 先进入要访问的文件夹，例如：

   ```powershell
   cd "$HOME\Documents"
   ```

3. 粘贴并执行：

   ```powershell
   irm https://gitee.com/caoqu/team-agent/raw/master/packages/cli/install/install-agentroam.ps1 | iex
   ```

4. 等待后台服务启动。若提示是否下载桌面 App，按自己的需要选择；下载后仍需打开安装文件。
5. 如果安装后命令暂时无法识别，关闭并重新打开 PowerShell。

### 安装结束看哪里

在电脑终端执行：

```bash
agentroam service status
```

重点看终端中的以下内容：

| 内容 | 用途 |
| --- | --- |
| `Open:` 后的地址、访问二维码 | 在手机或其他设备打开控制台 |
| `远程桌面授权地址` | 在运行 AgentRoam 的这台电脑上设置系统权限 |
| `配对码`、标注“手机扫码直接连接”的授权二维码 | 授权一台新设备访问 |

普通访问二维码只负责打开页面；标注“手机扫码直接连接”的授权二维码可直接完成配对。以二维码旁的文字为准。

只想查看访问地址时执行：

```bash
agentroam service url
```

后台安装完成后可以关闭终端，服务会继续运行，并在用户登录后启动。合盖、手动睡眠或关机仍可能中断访问。

## 2. 配对第一台手机

### 方法 A：扫描授权二维码（推荐）

1. 在被访问的电脑终端执行：

   ```bash
   agentroam pair
   ```

2. 找到标注“手机扫码直接连接”的二维码。
3. 用手机相机扫描，点击识别出的链接，在浏览器中打开。
4. 授权二维码有效时会直接进入控制台，无需再到电脑输入 `yes`。

二维码 5 分钟内有效，且只能使用一次。不要把授权二维码或包含授权信息的链接发给其他人。

### 方法 B：输入配对码，再由电脑批准

1. 在电脑执行 `agentroam pair`，保持这个终端窗口打开。
2. 手机打开 `agentroam service url` 输出的访问地址。
3. 在“连接你的设备”页面，填写电脑显示的配对码。
4. 在“设备名称”填写便于辨认的名字，例如“我的 iPhone”。
5. 点击 **配对并进入**。
6. 手机出现 **等待电脑批准**，下面显示一段核对短语。
7. 回到电脑终端，核对设备名称和短语，确认与手机显示完全一致。
8. 在“确认手机显示相同短语？”提示后输入 `yes`，按回车。
9. 手机自动进入控制台。

如果终端没有继续等待批准，可另开一个终端执行：

```bash
agentroam approvals
```

查看请求 ID 和短语，确认无误后执行以下命令；尖括号部分替换为实际内容，不保留尖括号：

```bash
agentroam approve <请求ID> --phrase "<手机显示的完整核对短语>"
```

配对码过期、已被使用或请求超时，都回电脑重新执行 `agentroam pair`。

### 已安装手机 App 的情况

打开 AgentRoam App，在 **连接服务器** 页面点击 **扫码连接**，允许使用相机，再扫描电脑 `agentroam pair` 生成的授权二维码。成功后直接连接。

如果使用 iPhone 浏览器，也可以在 Safari 打开页面后，点击 **分享 → 添加到主屏幕 → 添加**，以后从主屏幕图标进入；如果新入口要求配对，再按提示完成一次。

## 3. 多设备怎么配对

### 多台手机、平板或浏览器连接同一台电脑

每添加一台设备，重复一次：**电脑执行 `agentroam pair` → 新设备扫码，或填写配对码并在电脑批准**。

- 一台设备配对完成后，再为下一台生成新码；不要让多台设备共用同一个一次性二维码。
- 新设备配对不需要先删除旧设备。
- 不同浏览器、无痕窗口和清除浏览器数据后的访问，可能需要重新配对。
- 本机授权页面与公网地址是不同访问入口；电脑打开本机页面时如果要求配对，也要单独配对一次。

在被访问的电脑查看已授权设备：

```bash
agentroam devices
```

取消某台设备的访问资格：从列表复制对应设备 ID，再执行：

```bash
agentroam revoke <设备ID>
```

### 同一台手机连接多台电脑

1. 在每台被访问的电脑上分别安装并启动 AgentRoam。
2. 分别在每台电脑执行 `agentroam pair`。
3. 手机逐一打开对应电脑的访问地址，完成配对。
4. 给浏览器书签起不同名称，例如“家里 Mac”“办公电脑”。

每台电脑有自己的地址和设备授权；配对电脑 A 不会自动获得电脑 B 的访问权限。远程桌面系统权限也要逐台设置。

## 4. 在 Mac 上开启远程桌面授权

这一步必须在**运行 AgentRoam 的那台 Mac**操作。手机上的设备配对与 macOS 的屏幕、输入权限是两件事，都完成后才能远程查看和控制。

### 第一步：进入本机授权页面

1. 在 Mac 终端执行 `agentroam service status`。
2. 复制输出中的 **远程桌面授权地址**，在这台 Mac 的浏览器打开。
3. 地址通常形如 `http://127.0.0.1:实际端口/web`。使用终端打印的地址，不要自行固定成 3000 端口。
4. 如果出现“连接你的设备”，执行 `agentroam pair`，在本机浏览器填写配对码和设备名，再回终端核对短语、输入 `yes`。

### 第二步：找到“远程授权”盾牌

1. 进入控制台后，在顶部找到显示器图标，悬停提示为 **远程桌面 · 浏览器直播**，点击它。
2. 打开直播面板后，看 **浏览器直播** 标题旁边。
3. 点击盾牌图标 **远程授权**。
4. 弹出的“远程授权”面板中，会显示 **屏幕录制**、**辅助功能** 的授权状态，以及 **去授权** 按钮。

如果当前页面提示“打开本机授权页面”，说明你用的是远程地址。请回到运行 CLI 的 Mac，使用终端打印的本机授权地址重新进入，尤其不要在另一台电脑上打开它。

### 第三步：允许屏幕录制

1. 点击 **屏幕录制** 右侧的 **去授权**。
2. 在 macOS **系统设置 → 隐私与安全性 → 屏幕录制** 中，找到 **AgentRoam Remote Desktop**。部分 macOS 将这一项命名为“屏幕与系统音频录制”。
3. 打开该应用旁的开关；系统要求验证时，按提示输入 Mac 密码或使用 Touch ID。
4. 回到浏览器的“远程授权”面板。

屏幕录制权限用于传输电脑画面。

### 第四步：允许辅助功能

1. 点击 **辅助功能** 右侧的 **去授权**。
2. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中，找到 **AgentRoam Remote Desktop**。
3. 打开它旁边的开关，完成系统验证。
4. 回浏览器，点击 **重新检测**，检查两项是否都显示 **已授权**。

辅助功能权限用于远程鼠标和键盘操作。这里授权的是 **AgentRoam Remote Desktop**；不要仅给浏览器或终端开权限。

### 第五步：开启共享

1. 点击 **开启共享**。
2. 如果系统提示需要重新打开应用，回面板点击 **重启授权组件**，再点 **重新检测**。
3. 等待面板出现：**共享已开启，已配对手机可在直播列表选择本机桌面。**
4. 回到手机，按下一节查看实际画面。

## 5. 在手机上查看和控制电脑

1. 打开这台电脑的访问地址，使用已经配对的浏览器。
2. 点击顶部的远程桌面/显示器图标，打开直播面板。
3. 如果有多个直播会话，选择 **本机桌面**。
4. 先确认画面已经出现并能更新。
5. 点击 **开始控制**，再点击画面操作；需要输入文字时点击 **键盘**。
6. 用完点击 **结束控制**，释放控制权。

如果显示 **其他设备操作中**，先在正在控制的设备上点击“结束控制”，再换另一台设备操作。多设备配对不代表可以同时抢占鼠标键盘。

想停止画面共享：在 Mac 本机页面打开 **远程授权 → 停止共享**。这不会代替设备撤销授权。

## 6. 日常启动、更新和收回访问

| 要做什么 | 在被访问电脑上执行 |
| --- | --- |
| 查看服务状态 | `agentroam service status` |
| 查看当前访问地址 | `agentroam service url` |
| 启动后台服务 | `agentroam service start` |
| 重启后台服务 | `agentroam service restart` |
| 停止后台服务 | `agentroam service stop` |
| 查看日志 | `agentroam service logs` |
| 给新设备配对 | `agentroam pair` |
| 查看已配对设备 | `agentroam devices` |
| 撤销一台设备 | `agentroam revoke <设备ID>` |
| 立即锁定远程访问 | `agentroam lock` |
| 解锁远程访问 | `agentroam unlock` |

**更新：** 重新执行第 1 节对应系统的安装命令即可，不需要手动改版本号。默认安装最新发布到 `preview` 通道的版本；如果之前自己设置过 `AGENTROAM_VERSION`，需要先取消该固定版本设置。

**锁定：** `agentroam lock` 会取消所有设备授权和待用配对。执行 `agentroam unlock` 后，旧授权不会自动恢复，需要重新执行 `agentroam pair` 为设备授权。

**地址变化：** 完整重启服务或电脑后，临时公网地址可能变化。手机旧书签打不开时，重新执行 `agentroam service url` 获取地址；新地址要求配对时，按第 2 节重新操作。

## 7. 常见问题：先看这里

| 现象 | 去哪里看、怎么处理 |
| --- | --- |
| 手机打不开页面 | 电脑执行 `agentroam service status` 确认服务，再执行 `agentroam service url` 使用当前地址；如果输出的是局域网地址，手机需要处于同一局域网。 |
| 输入配对码后一直等待 | 看电脑终端的核对短语提示，确认后输入 `yes`；终端不再等待时执行 `agentroam approvals`。 |
| 扫码提示已过期或已使用 | 回电脑执行 `agentroam pair`，扫描新授权二维码。 |
| 本机网页又要求配对 | 本机地址和公网地址的浏览器授权分开保存，按本机页面要求单独完成配对。 |
| 找不到“远程授权” | 先打开顶部显示器图标对应的直播面板，再找“浏览器直播”标题旁的盾牌；使用运行 CLI 的 Mac 本机授权地址。已发布版本缺少入口时需升级。 |
| 提示电脑缺少远程桌面组件 | 在电脑重新执行安装命令升级 CLI；需要发布包已经包含对应组件。 |
| 权限开了但仍显示“待授权” | 确认系统设置里开的是 AgentRoam Remote Desktop；回页面点“重新检测”，系统要求重开时点“重启授权组件”。 |
| 手机看不到本机桌面 | 在 Mac 的“远程授权”面板确认两项已授权并已开启共享，再回手机刷新直播会话。 |
| 有画面但不能操作 | 检查辅助功能权限，并在手机点击“开始控制”；若其他设备在控制，先让其结束控制。 |
| Windows 没有桌面共享 | 当前 CLI 远程桌面组件只支持 macOS 14+ Apple Silicon；Windows 使用终端和文件功能。 |

## 核对说明

本文核对了安装脚本、CLI 配对命令、配对页、Web 控制台和远程授权面板的当前实现，未执行安装、系统授权或真实手机端到端测试，也不代表这些工作区变更均已发布。
